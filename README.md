# Zepto Sales Analytics Dashboard

**An Excel-based sales analysis and dashboard project**

This project uses Microsoft Excel to summarize sales performance and present key business metrics through KPI cards, PivotTables, and charts. The workbook is designed as a data-analytics portfolio project.

> **Disclaimer:** This is an independent learning and portfolio project. It is not an official Zepto product, dashboard, or business report.

---

## Dashboard Preview

Open the Excel workbook and select the **Report** sheet to explore the dashboard.

## Project Objectives

- Review overall sales and order performance.
- Compare sales across cities and product categories.
- Identify the top-performing products.
- Explore sales distribution across customer or business segments.
- Compare sales performance across weekdays.
- Present key metrics in a clear, easy-to-read dashboard.

## Dashboard Visuals

The **Report** sheet includes the following chart views:

1. **Sales Over Cities** — compares sales across cities.
2. **Sales Over Category** — shows the contribution of product categories.
3. **Top 10 Products** — highlights the products with the highest sales.
4. **Sales Distribution** — shows the sales split across the segments represented in the workbook.
5. **Sales Over Weekdays** — compares sales across days of the week.

## Workbook Structure

| Worksheet | Purpose |
|---|---|
| `Report` | Main dashboard with KPI cards and charts |
| `KPIS` | KPI calculations and summary metrics |
| `Charts` | Supporting summaries used by the visualisations |
| `Zepto_Dataset` | Source order-level dataset |

## How to View the Project

1. Download `final project excel.xlsx` from this repository.
2. Open the workbook in Microsoft Excel (desktop version recommended).
3. Select the **Report** sheet to view the dashboard.
4. Select **Zepto_Dataset** to inspect the underlying records.
5. If you change the source data, refresh the relevant PivotTables and charts and verify the KPI calculations.
